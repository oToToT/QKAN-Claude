# Data

`SN_m_tot_V2.0.csv` — monthly mean total sunspot number, version 2.0.

- Source: WDC-SILSO, Royal Observatory of Belgium, Brussels
  (<https://www.sidc.be/SILSO/datafiles>, file `SN_m_tot_V2.0.csv`), downloaded 2026-11-13.
- Licence: CC BY-NC 4.0. Cite as *SILSO World Data Center, International Sunspot Number
  Monthly Bulletin and online catalogue, Royal Observatory of Belgium.*
- Columns (`;`-separated): year, month, decimal year, monthly mean total sunspot number,
  standard deviation, number of observations, definitive/provisional marker.

The Gated QKAN-FWP paper uses 3,326 monthly records (1749-01 … 2026-02);
`qkanfwp.data.load_sunspots()` truncates the file to those records.

All other benchmark series (Bessel, damped SHM, NARMA5/10, delayed quantum control,
Jaynes–Cummings) are generated by `qkanfwp/data.py`.
